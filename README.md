# 🧠 Simple Quiz App (React/Next.js)

A clean and minimal quiz app built using **React** and **Next.js**, focusing on beginner-friendly concepts like:

- `useState` for managing state
- `props` to pass data into components
- Conditional rendering
- Reusable components

---

## ✨ Features

- ✅ One question shown at a time
- ✅ Multiple-choice options
- ✅ Score tracking
- ✅ Final results page
- ✅ Clean, responsive UI using inline styles

---

## 🧱 Tech Stack

- **Framework:** Next.js 
- **Language:** JavaScript (ES6+)
- **UI:** Inline CSS (no external styling libraries)
- **State Management:** React `useState` hook
